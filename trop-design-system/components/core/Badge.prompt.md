**Badge** — rounded pill for capability tags (e.g. "Idempotent", "SQLite-backed") and metadata. `default` tone is muted-on-panel; `accent` is harbor-green tinted.

```jsx
<Badge>Idempotent</Badge>
<Badge tone="accent">Local-only</Badge>
```

Always weight 800, pill radius. Group several in a wrapping flex row.
