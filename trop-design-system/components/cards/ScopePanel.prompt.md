**ScopePanel** — trop's honest "what it is / isn't" panel on a seafoam wash. Left column is heading + intro; right column lists in-scope items and non-goals.

```jsx
<ScopePanel
  title="One narrow problem"
  intro="Stable localhost ports for one user across local worktrees."
  inScope={["Directory-aware reservations", "Optional tags", "Concurrent local callers"]}
  nonGoals={["System-wide enforcement", "Multi-user coordination", "Container orchestration"]} />
```

Shadowless. Dashes are harbor-green. Keeps the brand's candid, no-hype voice.
