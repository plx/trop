Port reservations for agentic coding

trop

Stable, directory-aware localhost ports.

A small Rust CLI that replaces hardcoded port numbers with sticky, idempotent reservations — so concurrent worktrees and local agents never collide.

Idempotent Directory-aware Cross-process safe

Why trop

One job, done predictably

Repeated calls in one worktree return the same reservation — scripts stay stable across restarts. Reservations are pruned once their worktree is removed. No teardown hooks in every script. Safe to invoke from many processes at once — independent agents reserve without a shared spreadsheet.
